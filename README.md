# Anchor

Anchor is a live futures trading system built for IBKR.

## What it does

- Trades futures on an IBKR paper account
- Focuses on MES and MNQ
- Runs signal generation, execution, and trade management
- Includes a UI for monitoring the system

## Stack

- Backend: Python, FastAPI, SQLAlchemy, Celery
- Frontend: React, TypeScript, Vite
- Database: PostgreSQL
- Broker: IBKR
